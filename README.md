## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/arjun-00012/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
npm run build
```

Production static assets will be output to the `dist/` folder, ready for deployment to Vercel, Netlify, Render, or GitHub Pages.
